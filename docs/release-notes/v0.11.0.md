# WardSen v0.11.0

`v0.11.0` is a stable WardSen release. The Windows MSI and macOS Apple Silicon DMG are unsigned artifacts; verify the matching checksum before installing and expect platform warnings until code signing and notarization are configured.

## Changes

- Promoted WardSen to the `v0.11.0` stable release line with stable GitHub release publishing.
- Added Settings-based GitHub release checks that compare metadata only and never auto-download, install or run updates.
- Kept stable installations on stable releases instead of offering newer release candidates.
- Added first-run onboarding for vault setup, unlock state and delivery readiness.
- Added clearer Bitwarden, KeePassXC, Yopass and external-provider setup guidance in the app.
- Gated Password Pusher and Onetime Secret behind local environment checks and explicit operator opt-in.
- Improved Yopass CLI discovery for standard Go install folders on Windows and Unix-like systems.
- Bounded desktop local-service proxy responses before buffering them in the Tauri shell.
- Pinned release and CI workflow actions more tightly for repeatable release evidence.

## Steps

1. Download the Windows MSI or macOS Apple Silicon DMG from this release.
2. Download the matching `SHA256SUMS-*.txt` file and verify the installer checksum.
3. On Windows, run the unsigned MSI only after checksum verification. Treat SmartScreen or Defender blocks as release issues.
4. On macOS, open the unsigned DMG only after checksum verification. If macOS blocks the verified local copy after dragging WardSen to Applications, run `xattr -dr com.apple.quarantine /Applications/WardSen.app`.
5. Install and verify the official Bitwarden `bw` CLI, then use **Vaults > Account Access > Terminal login / unlock** for Bitwarden accounts.
6. Configure optional delivery providers in the local service environment, restart WardSen, then enable them from **Settings > Optional Delivery Providers** only after **Check configuration** passes.
