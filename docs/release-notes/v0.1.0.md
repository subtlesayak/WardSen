# WardSen v0.1.0-rc.31

Unsigned prerelease with a Bitwarden Send creation fix for rc.30 users.

## Install Or Update

Windows:

1. Download the Windows installer from this release's assets.
2. Run the installer.
3. If Windows SmartScreen warns that the publisher is unknown, choose **More info** and then **Run anyway** only if you trust this unsigned prerelease.
4. Open WardSen from the Start menu.

macOS:

1. Download the macOS DMG from this release's assets.
2. Open the DMG.
3. Drag WardSen into Applications.
4. Open WardSen from Applications.
5. If macOS says `"WardSen" is damaged and can't be opened`, keep WardSen in Applications, open Terminal, and run `xattr -dr com.apple.quarantine /Applications/WardSen.app`. If Terminal prints `Operation not permitted`, run the same command with `sudo`.

Provider setup:

1. Install the provider tool you want to use, such as Bitwarden CLI `bw` or KeePassXC.
2. If WardSen cannot find the tool, use the install button and copyable help shown in the app.
3. For Bitwarden first login, use **Terminal login**, then return to WardSen and select **Import session**.

Optional verification:

1. Download the matching `SHA256SUMS-*.txt` asset.
2. Compare the installer checksum before opening the installer.

## Changes

- Fixed Bitwarden Send creation after rc.30 could fail with `missing required argument 'data'`.
- WardSen now uses Bitwarden CLI's encoded `send.text` create flow for Sends, piping both the JSON payload and encoded payload through stdin instead of putting credential text in process arguments.
- Added regression coverage for Bitwarden Send's two-step `bw encode` then `bw send --fullObject create` flow.
