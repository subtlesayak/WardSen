# WardSen v0.1.0-rc.66

`v0.1.0-rc.66` is an unsigned security-review prerelease. It improves Bitwarden setup, terminal session verification, account deletion cleanup, credential lookup, live status-refresh guidance and custom secure text delivery. It is not a trusted end-user macOS release.

## Install Or Update

Download the matching installer and `SHA256SUMS.txt` file from the GitHub release and verify the checksum before installation.

- **Windows:** the MSI is an unsigned review artifact. Treat SmartScreen or Defender blocks as a release issue; do not override them for normal use.
- **macOS:** the DMG is an unsigned review artifact. After verifying the checksum and dragging a known WardSen review copy to Applications, reviewers may run `xattr -dr com.apple.quarantine /Applications/WardSen.app` in Terminal. This temporary quarantine removal is not code signing or notarization; a signed and notarized DMG is still required for normal use.

For Bitwarden, use the official [`bw` CLI](https://bitwarden.com/help/cli/). Open **Settings > Provider Capabilities > Bitwarden > Bitwarden CLI setup** to check availability, open the official guide, or verify an existing absolute `bw` path without restarting the app.

## Changes

- Bitwarden CLI setup now opens the official provider guide, re-checks availability and verifies an operator-selected absolute `bw` executable path before saving it locally.
- Bitwarden terminal handoff now verifies unlocked status, account email, server URL and Bitwarden user ID before WardSen keeps the session in memory.
- Managed account deletion now blocks concurrent account operations, quarantines the deterministic profile directory, retries pending cleanup on startup and rejects symlink/junction profile attacks.
- Credential Search now includes fuzzy fallback matching and an **All items** result-size option.
- Delivery now supports custom secure text links without storing the custom text in delivery metadata or audit logs.
- Delivery history now explains which locked Bitwarden Send vaults must be unlocked before live view/status refresh can run.

## Trusted Release Gate

Before offering WardSen as a normal macOS installer, configure Apple Developer ID signing and notarization secrets plus `MACOS_SIGNING_ENABLED=true`, run the release workflow, and verify the resulting DMG with `codesign`, `spctl`, and `xcrun stapler validate`. See the [installer signing guide](../installer-signing.md) and [release checklist](../release-security-checklist.md).
