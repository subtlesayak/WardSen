# WardSen v0.1.0-rc.56

`v0.1.0-rc.56` is an unsigned security-review prerelease. It focuses on open-source redistribution hygiene and stronger proof that WardSen does not persist credential secrets outside the provider/backend path. It is not a trusted end-user macOS release.

## Install Or Update

Download the matching installer and `SHA256SUMS-*.txt` file from the GitHub release and verify the checksum before installation.

- **Windows:** the MSI is an unsigned review artifact. Treat SmartScreen or Defender blocks as a release issue; do not override them for normal use.
- **macOS:** the DMG is an unsigned review artifact. There is no supported end-user workaround for a `cannot be verified` or `is damaged` warning. Do not use `xattr`, `sudo xattr`, or disable Gatekeeper. A signed and notarized DMG is required for normal use.

For Bitwarden, use the official [`bw` CLI](https://bitwarden.com/help/cli/). On macOS, an npm user-owned prefix is supported: WardSen detects `~/.local/bin/bw` after you install the CLI there and reopen the app.

## Changes

- Added explicit contribution rules for WardSen's local-first secret boundary, provider integrations, user-facing language, database/audit changes and required security checks.
- Restored the full Apache-2.0 license text and added a project `NOTICE` file for clearer redistribution hygiene.
- Added ADR 0002: credential secrets, provider sessions, delivery access passwords and secure URLs must not persist outside the provider/backend path.
- Extended `security:scan-secrets` with a WardSen canary prefix so release scans can prove generated outputs do not retain synthetic credential material.
- Added regression coverage for the WardSen canary scan behavior.

## Trusted Release Gate

Before offering WardSen as a normal macOS installer, configure Apple Developer ID signing and notarization secrets plus `MACOS_SIGNING_ENABLED=true`, run the release workflow, and verify the resulting DMG with `codesign`, `spctl`, and `xcrun stapler validate`. See the [installer signing guide](../installer-signing.md) and [release checklist](../release-security-checklist.md).
