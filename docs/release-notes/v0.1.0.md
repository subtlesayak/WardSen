# WardSen v0.1.0-rc.45

Unsigned prerelease with employee request workflows, delivery operation recovery and the same MSI-only Windows packaging policy as rc.42.

The previous unsigned Windows setup EXE was pulled after a Microsoft Defender `Trojan:Win32/Wacatac.B!ml` machine-learning detection. This release does not publish that NSIS setup EXE. Windows testers get an unsigned MSI only.

## Install Or Update

Windows:

1. Download `WardSen_0.1.0_x64_en-US.msi` from this release's assets.
2. Verify the checksum with `SHA256SUMS-windows-x64.txt`.
3. Run the MSI only if you trust this unsigned prerelease.
4. If Microsoft Defender blocks the MSI, leave it quarantined and report the detection details.

macOS:

1. Download the macOS DMG from this release's assets.
2. Open the DMG.
3. Drag WardSen into Applications.
4. Open WardSen from Applications.
5. If macOS says `"WardSen" is damaged and can't be opened`, keep WardSen in Applications, open Terminal, and run `xattr -dr com.apple.quarantine /Applications/WardSen.app`. If Terminal prints `Operation not permitted`, run the same command with `sudo`.

Provider setup:

1. Install the provider tool you want to use, such as Bitwarden CLI `bw` or KeePassXC.
2. If WardSen cannot find the tool, use the install button and copyable help shown in the app.
3. For Bitwarden first login, use **Terminal login**, then return to WardSen and select **Unlock from terminal session**.

Optional verification:

1. Download the matching `SHA256SUMS-*.txt` asset.
2. Compare the installer checksum before opening the installer.

## Changes

- Added an employee request catalog MVP for admins to publish metadata-only credential entries scoped to employees, teams or roles.
- Added employee identities with admin-controlled assigned email addresses and optional Person linking that requires the linked Person email to match.
- Added guarded bulk provisioning from selected People into Employee request identities.
- Added passwordless Employee Portal sign-in with admin-issued one-time codes, code-hash storage and session-token-hash storage.
- Added sender-labelled email draft handoff for employee sign-in codes without putting the code into a `mailto:` URL.
- Added employee-side request submission for allowed catalog entries only; employee endpoints return credential metadata, never raw secret values.
- Added catalog auto-approval policy for pre-approving matching employee requests without creating delivery links.
- Added admin approve, deny and replacement-link workflows for employee credential requests.
- Replacement links now revoke the previous provider link when possible and keep replacement count, previous delivery ID and latest replacement time on the original request.
- Delivery creation now supports idempotency keys through `operationId` or `X-WardSen-Idempotency-Key`.
- Completed same-session delivery operation retries can return the cached one-time URL without creating another provider link.
- Restarted sessions now refuse to recreate a completed operation when the one-time URL cache is gone, so operators can review intentionally.
- Bitwarden Send delivery can find provider-side sends by WardSen operation marker during reconciliation.
- Added API, repository, SQLite, provider and UI regression coverage for employee requests, catalog policy enforcement and delivery operation recovery.
- Fixed a macOS CI-only ordering assumption in the employee replacement-link API test before publishing this installer release.
