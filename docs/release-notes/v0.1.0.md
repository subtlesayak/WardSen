# WardSen v0.1.0-rc.55

`v0.1.0-rc.55` is an unsigned security-review prerelease. It focuses on layered rate limiting, safer Ente Paste manual handoff, clearer identity editing, dependency updates and release provenance maintenance. It is not a trusted end-user macOS release.

## Install Or Update

Download the matching installer and `SHA256SUMS-*.txt` file from the GitHub release and verify the checksum before installation.

- **Windows:** the MSI is an unsigned review artifact. Treat SmartScreen or Defender blocks as a release issue; do not override them for normal use.
- **macOS:** the DMG is an unsigned review artifact. There is no supported end-user workaround for a `cannot be verified` or `is damaged` warning. Do not use `xattr`, `sudo xattr`, or disable Gatekeeper. A signed and notarized DMG is required for normal use.

For Bitwarden, use the official [`bw` CLI](https://bitwarden.com/help/cli/). On macOS, an npm user-owned prefix is supported: WardSen detects `~/.local/bin/bw` after you install the CLI there and reopen the app.

## Changes

- Added layered local API rate limits. All local API requests are capped, and vault login, unlock, terminal handoff, terminal-handoff claim, and employee sign-in code routes have stricter per-route limits.
- Hardened Ente Paste manual handoff. WardSen now copies only credential title, username and password to the local clipboard; URLs, TOTP secrets and notes are excluded.
- Changed Ente Paste manual delivery IDs to use opaque operation-based IDs instead of hashes derived from credential handoff text.
- Improved People editing in the desktop UI, including notes, active state editing, copy feedback and edit/cancel controls.
- Improved Employee identity editing in the desktop UI while keeping the assigned email read-only after creation.
- Renamed delivery-history copy controls from provider ID to delivery ID so the UI matches WardSen's metadata model.
- Updated Fastify, `@vitejs/plugin-react`, `tsx`, React type definitions, and release attestation action pins.
- Documented the remaining Rust/Tauri advisory compatibility blocker without suppressing Cargo resolver behavior.

## Trusted Release Gate

Before offering WardSen as a normal macOS installer, configure Apple Developer ID signing and notarization secrets plus `MACOS_SIGNING_ENABLED=true`, run the release workflow, and verify the resulting DMG with `codesign`, `spctl`, and `xcrun stapler validate`. See the [installer signing guide](../installer-signing.md) and [release checklist](../release-security-checklist.md).
