# WardSen v0.1.0-rc.62

`v0.1.0-rc.62` is an unsigned security-review prerelease. It tightens desktop API isolation, moves weaker delivery providers behind explicit local operator opt-in, and fixes the packaged-installer release smoke check for the new proxy-only desktop API path. It is not a trusted end-user macOS release.

## Install Or Update

Download the matching installer and `SHA256SUMS.txt` file from the GitHub release and verify the checksum before installation.

- **Windows:** the MSI is an unsigned review artifact. Treat SmartScreen or Defender blocks as a release issue; do not override them for normal use.
- **macOS:** the DMG is an unsigned review artifact. After verifying the checksum and dragging a known WardSen review copy to Applications, reviewers may run `xattr -dr com.apple.quarantine /Applications/WardSen.app` in Terminal. This temporary quarantine removal is not code signing or notarization; a signed and notarized DMG is still required for normal use.

For Bitwarden, use the official [`bw` CLI](https://bitwarden.com/help/cli/). On macOS, an npm user-owned prefix is supported: WardSen detects `~/.local/bin/bw` after you install the CLI there and reopen the app.

## Changes

- Ente Paste and Yopass are disabled by default. They remain visible in Settings diagnostics, but delivery selection requires a local operator to review the warning and type the exact confirmation phrase.
- The server now rejects delivery creation for opted-out weaker providers, so a modified client cannot bypass the Settings warning.
- Settings now includes an **Optional Delivery Providers** section for enabling or disabling reduced-safeguard providers with exact confirmation.
- The packaged desktop webview no longer receives the desktop API token or direct local service URL. Requests go through a bounded Rust proxy command instead.
- The desktop proxy now decodes normal `Content-Length` and chunked local-service responses before handing JSON back to the webview.
- Desktop CSP now uses `connect-src 'self'` instead of allowing every localhost port.
- The packaged-installer smoke check now verifies the proxy-only CSP and registered Tauri proxy command.
- Added API, database, provider-conformance, web API, and Tauri config tests for provider opt-in and desktop proxy behavior.

## Trusted Release Gate

Before offering WardSen as a normal macOS installer, configure Apple Developer ID signing and notarization secrets plus `MACOS_SIGNING_ENABLED=true`, run the release workflow, and verify the resulting DMG with `codesign`, `spctl`, and `xcrun stapler validate`. See the [installer signing guide](../installer-signing.md) and [release checklist](../release-security-checklist.md).
