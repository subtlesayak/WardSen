# WardSen v0.1.0-rc.50

`v0.1.0-rc.50` is prepared from commit `a61b6ea`. It is not published yet: the macOS installer must be signed, notarized, and verified before this release is offered to Mac users.

## Install Or Update

Do not install an unsigned macOS DMG as a workaround for this release. When signed artifacts are available, download the matching installer and `SHA256SUMS-*.txt` file from the GitHub release, verify the checksum, then install normally.

For Bitwarden, use the official [`bw` CLI](https://bitwarden.com/help/cli/). On macOS, an npm user-owned prefix is supported: WardSen now detects `~/.local/bin/bw` after you install the CLI there and reopen the app.

## Changes

- Fixed recovery after Force Quit: each desktop launch selects its own trusted loopback port, so an orphaned local service cannot reject the new desktop session.
- Fixed Bitwarden CLI discovery for npm's user-owned prefix on macOS. This applies to vault search, Bitwarden Send, terminal login fallback, and the setup guidance.
- Added test coverage for the dynamic desktop service address and the `~/.local/bin/bw` resolution path.

## Release Gate

Before publishing, configure the Apple Developer ID signing and notarization secrets plus `MACOS_SIGNING_ENABLED=true`, run the release workflow, and verify the resulting DMG with `codesign`, `spctl`, and `xcrun stapler validate`. See the [installer signing guide](../installer-signing.md) and [release checklist](../release-security-checklist.md).
