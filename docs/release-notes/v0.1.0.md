# WardSen v0.1.0-rc.14

WardSen v0.1.0-rc.14 is the latest installer prerelease for WardSen, a local-first desktop credential dispatch hub.

## First User Install

Windows:

1. Download `WardSen_0.1.0_x64-setup.exe` from the release assets.
2. Run the installer.
3. If Windows SmartScreen warns that the publisher is unknown, choose **More info** and then **Run anyway** only if you trust this prerelease.
4. Open WardSen from the Start menu.
5. If WardSen says it cannot reach the local service, click **Restart service and retry**. If the same message returns, read the **Desktop service check** lines in the error banner and share them with the maintainer.

macOS Apple Silicon:

1. Download `WardSen_0.1.0_aarch64.dmg` from the release assets.
2. Open the DMG.
3. Drag WardSen into the Applications folder.
4. Open WardSen from Applications.
5. If macOS blocks the app because it is from an unidentified developer, go to **System Settings > Privacy & Security** and allow WardSen only if you trust this prerelease.
6. If macOS says `"WardSen" is damaged and can't be opened`, keep WardSen in Applications, open **Terminal**, run:

```bash
xattr -dr com.apple.quarantine /Applications/WardSen.app
```

Only remove quarantine for the WardSen prerelease you intentionally downloaded from this repository. Signed and notarized releases should not require this step.

Checksums:

1. Download the matching `SHA256SUMS-*.txt` file for your platform.
2. Compare the checksum before installing if you want to verify the downloaded file was not corrupted.

## What's Included

- Localhost-only Fastify API for provider, account, people, credential search, delivery and batch workflows
- React/Vite administration interface for vaults, credential search, people, deliveries and provider capabilities
- Tauri 2 desktop shell that bundles the web interface and starts the local API server
- Bitwarden credential adapter using the official `bw` CLI
- Bitwarden Send delivery adapter using the official `bw` CLI
- KeePassXC credential adapter using `keepassxc-cli`
- Provider-neutral scaffolds for 1Password, Proton Pass and Keeper
- SQLite metadata persistence with migration contracts
- Safe audit logging, redaction helpers and in-memory session handling
- Cross-origin request protection with actionable frontend error help
- Visible app version label in the desktop interface
- Desktop recovery action that restarts the bundled local service when the first API connection fails
- Desktop service diagnostics when restart still cannot make the local API reachable
- Desktop local-service startup fixes for Windows path normalization, writable data directory selection and trusted desktop preflight requests
- Responsive desktop layout fixes so the left sidebar stays anchored while the workspace content scrolls independently
- Easier destructive-action confirmations in the UI while preserving server-side confirmation tokens
- Sticky floating error help so action failures stay visible while the workspace is scrolled
- Actionable missing-provider-tool errors when `bw`, `keepassxc-cli` or another provider CLI cannot be found
- Non-terminal provider setup actions that link users to official install/download pages
- Desktop install/download actions now use the Tauri system-browser opener so clicking them works in packaged builds
- Provider setup errors include copyable install links for users whose default browser does not open correctly
- Provider setup errors include copyable Terminal, PowerShell or Command Prompt recovery commands for advanced users
- macOS first-install notes cover the unsigned-prerelease `"WardSen" is damaged and can't be opened` Gatekeeper message
- Windows and macOS prerequisite and packaging helper scripts
- CI, Dependabot, security documentation, threat model and release checklist

## Install Status

This prerelease includes working unsigned installer artifacts for validation and early testing.

Attached installer assets:

- `WardSen_0.1.0_x64-setup.exe`
- `WardSen_0.1.0_x64_en-US.msi`
- `WardSen_0.1.0_aarch64.dmg`
- `SHA256SUMS-windows-x64.txt`
- `SHA256SUMS-macos-arm64.txt`

These builds are unsigned. Windows SmartScreen and macOS Gatekeeper may warn until signing certificates and notarization credentials are configured.

See `docs/installer-signing.md` for the Windows Authenticode and Apple Developer signing setup. The release workflow is already structured so later signed builds can replace the prerelease assets.
